# Habitudes

Suivi d'habitudes personnel et privé. Ajoute une habitude, coche-la chaque jour, suis ta série et ton taux de complétion sur 30 jours.

100 % côté client : les données restent dans le navigateur (`localStorage`), rien n'est envoyé à un serveur. Ça veut dire aussi qu'elles ne se synchronisent pas entre appareils pour l'instant — chaque navigateur a ses propres données.

## Démarrer en local

```bash
pnpm install
pnpm run dev
```

## Vérifications

```bash
pnpm run typecheck
pnpm run test
pnpm run build
```

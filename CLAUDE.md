Commencer par `AGENTS.md`, `.claude/skills/finance/SKILL.md`, `docs/STATUS.md` s’il existe, puis `docs/PLAN.md`.

Le nom de l’application est Finance, le dépôt est Finance1. L’application initialement trouvée était un suivi d’habitudes ; ne pas déduire une application financière complète du seul nom du dépôt. Le code et les preuves actuels déterminent l’avancement.

Les sous-agents sont décrits dans `.claude/agents/finance-*.md`. Les utiliser pour les lots qui peuvent avancer indépendamment et pour la relecture des changements sensibles. Si l’environnement n’offre pas de sous-agents, exécuter le travail disponible et expliciter la limite de revue.

Le coffre local utilise Web Crypto et un export chiffré. Les données Notion réelles restent hors Git. Ne pas remplacer un manque d’accès Notion par des chiffres de mémoire et ne pas annoncer de cloud automatique non configuré.

Continuer dans le périmètre déjà autorisé : développer, tester, corriger et publier le code Finance1 avec les protections en place. Ne pas activer de service payant, de connexion bancaire ou d’hébergement non défini. Ne jamais accorder de permissions supplémentaires pour contourner un blocage.
